### Common ports

Here follows the most common ports for different operating systems

----------

### Domain Controllers
 - UDP 123 - NTP (W32Time)
 - TCP/UDP 53 - DNS
 - TCP/UDP 88 - Kerberos
 - TCP 135 - RPC
 - TCP/UDP 389 - LDAP
 - TCP 445 - SMB
 - TCP/UDP 464 - Kerberos password change
 - TCP 636 - LDAP SSL
 - TCP 3268 - LDAP GC
 - TCP 3269 - LDAP GC SSL

### Windows client / server
 - TCP 135 - RPC
 - TCP 139 - NetBios
 - TCP 445 - SMB
 - TCP 1433 - MSSQL
 - TCP 3389 - Remote Desktop (RDP)
 - TCP 5895 - WinRM

### Linux server
 - TCP 22 - SSH
